# SkillGap Radar

A full-stack web-application that analyzes a user's skills for a chosen role, identifies missing skills, and stores historical results for future analysis.

## Features

- Select a role and skills
- Compute skill gaps in real time
- Backend visualization & error handling
- Persistence layer
- View analysis history in a table
- Environment-based configuration
- Deployment-ready architecture

## Tech Stack

### Frontend
React, Vite, React Router

### Backend
Node.js, Express, SQLite
